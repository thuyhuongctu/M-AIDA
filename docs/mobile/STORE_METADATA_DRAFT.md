# Store metadata draft

## Shared positioning

- Name: **M-AIDA Research**
- Category: Education / Productivity (final category requires review)
- Short description: **Human-verified data extraction for meta-analysis research.**
- Core promise: Import a permitted research PDF, review the draft extraction, explicitly verify fields, lock the approved record, and export locked studies.
- Required disclaimer: M-AIDA assists research workflows; it does not replace researcher judgment, institutional authorization, or independent validation.

## Review notes

Explain the complete test path, provide a functioning review environment, and state clearly whether the build uses live extraction or the labeled rehearsed fallback. Do not imply that fallback output is live AI output. If authentication is added, provide a review account that does not expose real research records.

## Screenshot set

Capture on physical devices after final branding: extraction start, draft result with confidence, human verification, lock warning, export summary, offline/error state, Privacy link, and Support link. Screenshots must show current UI and must not include copyrighted PDFs, personal data, unpublished research, or unsupported claims.

English and Vietnamese store copy should be reviewed by the final publisher after the CTU agreement. Do not use CTU marks or claim CTU endorsement until written permission covers that exact use.
