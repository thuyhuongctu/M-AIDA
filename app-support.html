M-AIDA Research App Support

M-AIDA supports human-verified extraction of meta-analysis research records. The mobile build is currently for internal evaluation and is not yet publicly distributed.

Before reporting a problem

  1. Confirm that the device is online.
  2. Check the in-app Backend status.
  3. Record the app version, device model, operating-system version, and the exact action that failed.
  4. Do not attach confidential PDFs or unpublished data to a public report.

Report a problem

Open an issue in the M-AIDA GitHub repository. Security or privacy reports should contain only the minimum non-sensitive information needed to establish contact.

Known release limitation

Public distribution remains blocked until the CTU intellectual-property agreement, production operator, secure production access model, data disclosures, support process, and final store listing are approved.
